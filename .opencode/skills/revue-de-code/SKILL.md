---
name: revue-de-code
description: Revue de code selon la checklist de l'équipe (nommage, code mort, complexité). À utiliser avant chaque commit ou PR.
---

Relis le code fourni en vérifiant :
1. Les noms de variables et de fonctions sont clairs et en anglais.
2. Il n'y a pas de code commenté ou mort à supprimer.
3. Aucune fonction n'est trop longue ou trop imbriquée.

Rends tes retours en liste à puces, du plus grave au moins grave.
